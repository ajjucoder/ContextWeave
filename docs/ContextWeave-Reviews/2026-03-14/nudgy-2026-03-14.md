## Flaws Found

Ordered by severity. Each finding is a single issue with a likely root-cause area and concrete fix.

### P0 (Critical — blocks adoption)
1. **Tauri invoke/event boundary tracing is broken**: `cw_flow("handleStart")` and `cw_flow("dismiss")` returned no outgoing flows even though both functions cross real runtime boundaries via `invoke()` / `listen()` / `emit_all()` -> likely root cause in [`src/mcp/tools/flow.ts`](/Users/aejjusingh/Developer/ContextWeave/src/mcp/tools/flow.ts) and event edge synthesis in [`src/core/event-edge-synthesis.ts`](/Users/aejjusingh/Developer/ContextWeave/src/core/event-edge-synthesis.ts) -> fix by adding first-class Tauri framework edges for `invoke("command")`, `listen("event")`, and `emit_all("event")`, then include those edge kinds in flow traversal.
2. **Common React/Zustand property-style symbols are missing from the index**: Exact query `updateSession` did not retrieve the real store definition; the capsule fell back to `App.tsx` consumer context and said the symbol was not found -> likely root cause in TypeScript symbol extraction in [`src/core/parser.ts`](/Users/aejjusingh/Developer/ContextWeave/src/core/parser.ts) and query patterns such as [`src/core/queries/typescript.ts`](/Users/aejjusingh/Developer/ContextWeave/src/core/queries/typescript.ts) -> fix by indexing interface members and object-literal property methods so store/action names are first-class symbols.
3. **Broad capsules can be confidently wrong**: `cw_capsule("window management")` reported HIGH confidence / VERY_LOW uncertainty while missing `toggle_tray_panel` and the core show/hide command functions -> likely root cause in confidence calibration in [`src/capsule/confidence.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/confidence.ts) and ranking/packing in [`src/capsule/generator.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/generator.ts) -> fix by tying confidence to required-path coverage for the detected intent, not just internal retrieval scores.

### P1 (Important — degrades quality)
1. **Budget utilization is terrible on broad queries**: 18%-25% utilization on 8000-token budgets means the system is leaving obvious recall headroom unused -> likely root cause in [`src/capsule/packer.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/packer.ts) and fallback/expansion logic in [`src/capsule/content-fallback.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/content-fallback.ts) -> fix by backfilling more relevant pivots when utilization is low and confidence is below a threshold.
2. **Docs/config noise pollutes the index and ranking**: `cw_status()` warned that 77% of indexed files were non-source, and docs/config repeatedly surfaced in exact or architectural searches -> likely root cause in source weighting and ignore policy in [`src/core/indexer.ts`](/Users/aejjusingh/Developer/ContextWeave/src/core/indexer.ts), [`src/utils/config.ts`](/Users/aejjusingh/Developer/ContextWeave/src/utils/config.ts), and [`src/utils/directory-weights.ts`](/Users/aejjusingh/Developer/ContextWeave/src/utils/directory-weights.ts) -> fix by defaulting to source-first ranking and demoting docs/config unless the query explicitly asks for them.
3. **`cw_impact` under-reports real dependents**: `cw_impact("start_session")` returned `No dependents found`, which is false in any practical sense because `handleStart` invokes it and `main.rs` registers it into the command surface -> likely root cause in [`src/mcp/tools/impact.ts`](/Users/aejjusingh/Developer/ContextWeave/src/mcp/tools/impact.ts) sharing the same missing runtime-edge graph -> fix by treating framework registrations and frontend invokes as impact edges, not just static code references.
4. **Follow-up read suggestions are weak in real workflows**: Task A suggestions pointed at `start_session` / `end_session` instead of `skip_gap` / `complete_gap`, and Task C had no useful follow-up guidance at all -> likely root cause in suggestion ranking inside [`src/capsule/formatter.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/formatter.ts) and pivot scoring in [`src/capsule/pivot-scorer.ts`](/Users/aejjusingh/Developer/ContextWeave/src/capsule/pivot-scorer.ts) -> fix by ranking follow-ups against unanswered query slots, not just local symbol scores.

### P2 (Moderate — papercut)
1. **`cw_stats` savings math is too optimistic to trust**: On a live session it estimated `~333 tokens` saved, but the measured task runs in this review were 30.1% worse than grep+read -> likely root cause in [`src/mcp/tools/stats.ts`](/Users/aejjusingh/Developer/ContextWeave/src/mcp/tools/stats.ts) only comparing capsule cost against a synthetic grep baseline while ignoring follow-up reads and recovery work -> fix by counting all CW follow-up tool output in the estimate or explicitly labeling it as capsule-only.
2. **`cw_recall` is practically useless for architectural questions**: `cw_recall("state synchronization")` returned nothing helpful despite repeated sessions on this repo -> likely root cause in observation coverage and BM25 recall in [`src/memory/search.ts`](/Users/aejjusingh/Developer/ContextWeave/src/memory/search.ts) and observation capture flow in [`src/mcp/tools/remember.ts`](/Users/aejjusingh/Developer/ContextWeave/src/mcp/tools/remember.ts) -> fix by improving memory seeding/auto-capture and boosting structural terms for architecture queries.
3. **`cw_status()` is missing benchmark-critical metadata**: It exposes counts and warnings, but not server version or actual index duration, which makes field reviews harder than they should be -> likely root cause in [`src/mcp/tools/status.ts`](/Users/aejjusingh/Developer/ContextWeave/src/mcp/tools/status.ts) -> fix by reporting version, last indexed timestamp, and last reindex duration directly.

## What Worked Well

- Exact-symbol lookup is solid when the symbol is already well indexed and function-shaped. `dismiss` and `toggle_tray_panel` both landed definition-first.
- `cw_overview` is genuinely useful for fast orientation. It was the best supporting tool in this review.
- For direct Rust-only static flows, `cw_capsule` + `cw_flow` gave a compact picture quickly. `start_session` -> `start_new_session` / `run_session` worked.
