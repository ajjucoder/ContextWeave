Process

From codebase to perfect context.
In milliseconds.

Three steps from raw code to token-budgeted context for any coding agent.

01

Index

Tree-sitter parses your code into an AST dependency graph. Every symbol, every call, every import — mapped across 12 languages.

02

Query

Ask with natural language. The 7-phase pipeline resolves symbols, scores via BM25 + PageRank, and compresses to your token budget.

03

Deliver

Your agent receives exactly the code it needs. No noise, no waste, no missing dependencies.
