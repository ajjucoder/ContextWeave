How It Works

From codebase to perfect context. Three steps.

Your agent asks a question. ContextWeave delivers the exact code it needs — nothing more, nothing less.

01

Parse & Map

Tree-sitter parses every file into an AST dependency graph. Functions, classes, imports, call chains — all mapped across 12 languages in seconds.

02

Rank & Score

Natural language query hits the 7-phase pipeline. BM25 for relevance. PageRank for structural importance. Three-layer fuzzy matching catches what exact search misses.

03

Pack & Deliver

Results compressed into a token-budgeted capsule. Your agent gets exactly the code it needs, with full dependency context, within your token limit.

Capabilities

Everything your agent needs to understand code. Not just find it.

Most tools give your agent text matches. ContextWeave gives it comprehension.

AST Dependency Graph

Tree-sitter powered structural analysis across your entire codebase. Understands function calls, class hierarchies, imports, and symbol relationships — not just text patterns. This is what makes ContextWeave fundamentally different from grep-based context.

Token-Budgeted Capsules

Request 2K or 20K tokens. The pipeline delivers exactly what fits, ranked by structural relevance and importance.

Cross-Session Memory

Architectural decisions, conventions, and past insights persist across sessions. Context that compounds over time.

100% Local & Private

SQLite + tree-sitter on your machine. No cloud, no telemetry, no API keys. Your code never leaves.

Intelligent Search

BM25 + PageRank with three-layer fuzzy fallback: Porter stemming, trigram matching, Levenshtein correction. Finds what grep can't.

Engineered for Monorepo Scale

PageRank across 1M symbols in 556ms. Context capsules for 10M-line codebases in under 20 seconds. CSR compact adjacency, cached prepared statements, streaming iterators, and chunked transactions. We didn't just build for scale — we stress-tested it.
